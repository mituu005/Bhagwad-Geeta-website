# श्रीमद् भागवत कथा - पावन सप्रेम आमंत्रण वेबसाइट (Shrimad Bhagwat Katha Invitation Website)

भगवान श्रीकृष्ण एवं श्रीमद् भागवत महापुराण को समर्पित एक अत्यंत भव्य, पावन, पारंपरिक एवं आधुनिक तकनीकी से सुसज्जित डिजिटल आमंत्रण वेबसाइट।

---

## 🌟 मुख्य विशेषताएं (Key Features)

1. **पारंपरिक एवं राजसी सनातन थीम**:
   - दिव्य केसरिया (Royal Saffron), स्वर्ण (Pure Gold), गहरा राजसी नील (Deep Royal Blue) एवं मयूर पंख हरित (Peacock Green) रंग संयोजन।
   - पारंपरिक मंदिर वास्तुकला, स्वर्ण तोरण, स्वस्तिक, ॐ, मयूर पंख, बांसुरी, मंगल कलश एवं प्रज्वलित दीपकों के सजीव रूप।

2. **पूर्णतः शुद्ध हिन्दी एवं देवनागरी टाइपोग्राफी**:
   - `Tiro Devanagari Hindi`, `Noto Serif Devanagari`, एवं `Hind` फोंट्स का सुरुचिपूर्ण प्रयोग।

3. **भव्य मुख्य आमंत्रण (Hero Section)**:
   - कदम्ब वृक्ष के नीचे भगवान श्रीकृष्ण के बंशी वादन का मनोहारी दिव्य दृश्य।
   - स्वर्ण नक्काशीदार फ्रेम, श्लोक, आमंत्रण संदेश एवं "कथा कार्यक्रम देखें" स्मूथ स्क्रॉल बटन।

4. **कथा का दिव्य महत्व (Introduction Section)**:
   - श्रीमद् भागवत महापुराण का अलौकिक दिव्य ग्रंथ चित्र एवं भक्ति, ज्ञान, वैराग्य, मोक्ष के चार स्तंभ।

5. **अष्ट दिवसीय संपूर्ण कथा कार्यक्रम (All 8 Days Katha Schedule)**:
   - 18 दिसंबर 2026 से 25 दिसंबर 2026 तक के सभी 8 दिनों का संपूर्ण एवं सटीक पंचांग, तिथि, वार एवं प्रसंग।
   - स्वर्ण टाइमलाइन (Golden Connected Timeline) एवं विशेष दिवसों (प्रथम दिवस व अष्टम दिवस) का विशेष अलंकरण।

6. **अलौकिक झांकी एवं दर्शन दीर्घा (Devotional Image Gallery & Lightbox)**:
   - 8 उच्च-गुणवत्ता वाले भक्तिमय कलात्मक चित्र:
     1. भगवान श्रीकृष्ण बंशी वादन लीला
     2. श्री राधा-कृष्ण दिव्य युगल दर्शन
     3. गिरिराज गोवर्धन धारण लीला
     4. बालकृष्ण माखनचोरी लीला
     5. श्रीकृष्ण एवं सुदामा पावन मिलन
     6. पवित्र श्रीमद् भागवत महापुराण ग्रंथ
     7. दीपमालिकाओं से सुसज्जित भव्य देवालय
     8. मंगल कलश एवं वैदिक हवन कुंड
   - इंटरएक्टिव लाइटबॉक्स (फुल-स्क्रीन दर्शन, कथा प्रसंग विवरण एवं नेविगेशन)।

7. **समर्पित फ्लोटिंग म्यूजिक प्लेयर (Background Music System)**:
   - प्ले / पॉज़ बटन
   - म्यूट / अनम्यूट बटन
   - वॉल्यूम स्लाइडर
   - संगीत तरंग (Equalizer Visualizer) एनिमेशन
   - आसानी से भजन बदलने की सुविधा (`assets/js/music-config.js`)
   - वेब ऑडियो एपीआई (Web Audio API) आधारित मधुर बांसुरी व तानपुरा बैकअप।

8. **भगवद अमृत वचन (Divine Quotes)**:
   - महामंत्र एवं श्रीकृष्ण अमृत वचन स्वर्ण फ्रेम में।

9. **सपरिवार सादर आमंत्रण एवं सोशल शेयरिंग**:
   - कथा स्थल, दैनिक समय एवं आयोजक विवरण।
   - एक क्लिक में व्हाट्सएप (WhatsApp) पर निमंत्रण साझा करने की सुविधा।
   - गूगल कैलेंडर / आई-कैलेंडर (.ics) में जोड़ने की सुविधा।

10. **सजीव पुष्प वर्षा एवं एनिमेशन**:
    - स्क्रीन पर धीरे-धीरे गिरती गेंदे एवं गुलाब की पंखुड़ियां (पुष्प वर्षा चालू/बंद बटन सहित)।
    - प्रज्वलित दीपकों की लौ (Flickering Diya Flames)।

## 🎵 अपना मनपसंद भजन कैसे बदलें (How to Change Music)

बैकग्राउंड म्यूजिक बदलना बेहद आसान है:

1. अपनी ऑडियो फाइल (`.mp3` या `.wav`) को `assets/music/` फोल्डर में रखें।
2. `assets/js/music-config.js` फाइल खोलें:
```javascript
const KATHA_MUSIC_CONFIG = {
  // अपनी फाइल का नाम यहाँ लिखें:
  audioFilePath: "assets/music/your-bhajan-name.mp3",
  
  // भजन का नाम जो प्लेयर पर दिखेगा:
  trackTitle: "श्रीकृष्ण मधुर भजन",
  
  // ध्वनि स्तर (0.0 से 1.0):
  defaultVolume: 0.65
};
```
3. फाइल सुरक्षित (Save) करें। बस, आपका नया भजन बजने लगेगा!
